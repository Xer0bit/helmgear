# Changelog

## 0.2.2-rc.3 (unreleased)

First public preview of Helmgear, a fork of DeepSeek Harness.

### Added

- Control plane: template loader, Jev router, MCP gateway and task runner
- Tiered tools, an approval queue tied to the exact payload, and an append-only audit log
- Firecrawl, outbox, email, X and MCP bridge connectors
- Plan-first runs, session continuation, reply checks with escalation, and tool budgets
- Person-approved tenant memory, and lessons learned from rejected actions
- Batch runs and slot-based scheduled tasks
- Terminal and browser consoles
- Six business agent templates
- Evals graded by code, with a regression gate
